## PICO-8's limitations

The PICO-8 fantasy console imposes a number of strict limitations on games. The screen is 128 x 128 pixels. The sound system has exactly four channels, which are shared by both the music and game sfx. Even in the source code itself you have a fixed token budget, which means that having too much code is effectively a compiler error.

The creative process of negotiating the vision for the game against these limitations was an epiphany for me as it resulted in a better finished product than I could have created on a less opinionate platform. It's a lesson I've carried with me in how I approach anything from design systems to API design.

## Web version and app

PICO-8 includes functionality to export games for the web, but that built-in web wrapper involves a difficult-to-use on-screen gamepad. Tailbone is a one-button game, which means allowing a press anywhere on the screen to control gameplay is a preferable UI to a virtual gamepad.

By tinkering with the exported HTML file I was able to replace the virtual gamepad with a click handler that triggered a button press within the PICO-8 engine. This made the game playable on mobile devices, unlocking the next phase of the project, which saw the game published on the App Store using Apache Cordova to wrap the web version. To the best of my knowledge it might have been the first PICO-8 game on the App Store.
