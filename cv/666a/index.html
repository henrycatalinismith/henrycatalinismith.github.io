666a.se

Work environment email alerts

666a.se was a free service I built to send configurable email alerts about filings at the Swedish Work Environment Agency. It was inspired by an unfulfilled need I saw during my time as a union representative at Spotify and had something like 100 users by the time I shut it down for cost reasons.

Rails, SQLite, Sendgrid

Incremental web scraping

The Swedish Work Environment Agency does not provide a notification mechanism of any kind. In order to determine which filings are new today you must compare today’s dataset with yesterday’s. Around 250,000 filings are processed per year, so refetching the full dataset is not an option without risking an IP block from an angry network administrator.

I devised an incremental web scraping tool which stored all previously seen filings in a database and rescanned daily to catch new ones. This made it possible to identify new filings within at worst a day or two, at a cost of only a few minutes per day of operation at a rate of a request per second.

Extreme budget architecture

Nobody in the Swedish labour movement is particularly rich so the service needed to be free to use. This created a strong incentive to make the service as cheap to run as possible.

The highly schedule-driven nature of the load patterns together with the service’s overall low write volume meant it was possible to run the entire thing as a single Ruby process using SQLite as the database. This was possible to run on Fly.io for less than $10 per month.

AI-assisted translation workflow

Later in the lifecycle of the project I expanded its scope to include English translations of Swedish labour laws. The English translations published by the Swedish government were out of date and my goal was to catch them up to the latest Swedish versions.

I used the OpenAI API to generate a glossary of Swedish-English phrase pairs based on the existing translations. Using this glossary as a reference made it possible to deliver updated English translations with a high level of confidence about the fidelity of the update in relation to the linguistic choices made by the original translators.
