After getting my JAWS setup in place recently, NVDA was next on the agenda. It was easy enough to install, which left me with enough leftover time and energy to make an attempt at loading http://localhost:3000 on it in order to be able to test unmerged changes. It went better than expected!

I found out you can use http://10.0.2.2:3000 to access port 3000 on the host machine. No config needed.

Very cool indeed to be this well-equipped. NVDA is a little bit nicer to use somehow than JAWS, too.

Plus, since setting up the JAWS thing, I learned that it’s a violation of the license to use the trial version of JAWS for accessibility testing. So NVDA seems like it’s going to be my go-to option for Windows screen reader testing.
