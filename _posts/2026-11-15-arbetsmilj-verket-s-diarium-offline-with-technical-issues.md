---

A few times a year I update
[arbetsmiljo.github.io](https://arbetsmiljo.github.io) with the latest public
data from Arbetsmiljöverket’s diarium, and when I went to do it this morning I
realized it’s been offline for apparently several weeks. All HTTP requests get
redirected to a [page with the word “systemunderhall” in its
URL](https://www.av.se/om-oss/diarium-och-allmanna-handlingar/systemunderhall/),
which contains the following message.

> Arbetsmiljöverkets webbdiarium är stängt på grund av driftstörningar
>
> Senast uppdaterad **2026-11-04**

I’m not really sure what’s going on, to be honest. It’s a bit of a mixed
message with the words “driftstörningar” (operational disturbances) and
“systemunderhåll” (system maintenance) together in one place like that, and
that soon-two-weeks-old timestamp suggests it’s been down for a relatively long
time.
